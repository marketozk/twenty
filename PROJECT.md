# Twenty CRM: общение с клиентами вместо SaleBot

Дата фиксации: 26.10.2026 (Москва).

Цель: сделать Twenty единым рабочим местом для общения с клиентами Telegram/MAX, CRM, автоматизаций и ИИ с доступом к данным тендерного робота. В конечном решении SaleBot не требуется для работы переписки.

Уточнение 26.10.2026: несколько менеджеров с отдельными входами и правами могут участвовать в одном клиентском диалоге; ИИ должен иметь максимальные прикладные полномочия, включая операции CRM/робота по установленным правилам. Основной вариант каналов — существующие юзерботы.

## Код и репозитории

Эта папка — локальная копия нашего форка: https://github.com/marketozk/twenty.

- `origin` — `marketozk/twenty`, наши изменения.
- `upstream` — `twentyhq/twenty`, исходный проект.
- Начальная ревизия форка: `729f6236126eddaa68d176fb766bc349b19de11d`.
- Ветка постановки задачи: `codex/omnichannel-requirements`.
- `packages/` — исходники Twenty; структура upstream сохранена.
- `Research/omnichannel_crm/` — постановка задачи и дальнейшие исследования/проектирование.

Новый код этой доработки размещается в этом проекте. Точное расположение модулей в `packages/` либо отдельных компонентов определяется исследованием, без дублирования существующих механизмов Twenty.

Исходники существующих Telegram/MAX-коннекторов пока остаются в их прежних проектах. Перенос или выделение нужных частей должен сохранить лицензии, историю и границы сервисов; копировать весь старый проект вместе с конфигами, сессиями и данными нельзя. Сейчас эти компоненты не перенесены и не изменены.

## Текущее состояние

Выполнено: создана папка на Рабочем столе, скачан исходный код нашего форка, записаны требования и предварительный план. Проведено исследование исходников Twenty, Telegram/MAX-коннекторов и API робота; результаты и границы проверки находятся в `Research/omnichannel_crm/research.md`. Клон содержит исходники выбранной ветки, история Git первоначально загружена с глубиной 1. Поддержка длинных Windows-путей включена локально для этого репозитория.

Демо обновлено с официального образа 2.50.0 до 2.51.0 по отдельной просьбе пользователя; проверки и резервная копия перечислены в отчёте обновления. Маршруты сообщений SaleBot не переключались. Исходники форка по-прежнему указывают 2.52.0: ветка разработки и установленный стабильный релиз различаются.

Не выполнено: выбор архитектуры SDK/ядра, разработка чатов, установка зависимостей и сборка/деплой нашего изменённого кода. Обновление официального образа не означает реализацию проекта омниканальной CRM.

Выполненный разрешённый объём: фиксация требований, подготовка проекта и исследование. Порядок дальнейшей работы — Design → Plan → Review → Implement. Полнота нужной функциональности не заменяется обещанием выпустить только ИИ-черновики или только Telegram.

Установка и команды upstream находятся в [README.md](README.md) и [CLAUDE.md](CLAUDE.md). Они здесь не выполнялись. [Инструкция разработки приложений](packages/twenty-docs/developers/extend/apps/getting-started/quick-start.mdx) поддерживает macOS/Linux и рекомендует WSL 2 на Windows. Папка на Рабочем столе — место исходников и документов; среду сборки и тестирования нужно выбрать на этапе исследования.
