## Новая регрессия

**C5 — Low, N-15.** Порождена сочетанием двух правок: B5c (пара policyId/policyVersion у Command теперь NOT NULL и для human-команд) и C3 (индекс Command по policyId/policyVersion/state).

- **Сценарий:** очистка по событию `policy.changed` (`access-control.md:27`) «создаёт cancel outbox для Commands по индексам». Под этот индекс попадают и human-команды, ведь у них теперь тоже заполнена версия. Буквальная реализация отменит pending-ответ менеджера после публикации новой политики. Это противоречит `spec:95` («human dispatch не требует совпадения captured version с head»).
