## Граница готовности

Готовы сборка, обновление и исследование исходников. Новые чаты, собственные ACL, audit и fence не реализованы. Rollback/race/revoke/email/import regression будут постоянными тестами соответствующих изменений, а не отдельными выбрасываемыми прототипами.

Служебные таблицы будут в core той же БД с workspaceId, вне autogenerated CRUD; writer получает executor текущей транзакции. Точные существующие файлы и новые пути перечислены в карте реализации.

## Откат обновления

Новая копия состояния не создавалась по просьбе пользователя. Автоматический downgrade после миграций не выполняется: возврат образа сам по себе не возвращает БД. Сбой требует отдельного анализа состояния и согласованного восстановления, без database:reset.
