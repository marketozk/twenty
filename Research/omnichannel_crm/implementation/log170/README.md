# LOG170 - аудит полного жизненного цикла (`create`, `update`, `delete`) и каскадных удалений `navigationMenuItem`

Проверки доработки завершены. ROB765 остаётся In Progress.
[Дизайн](design.md), [ревью решения](design-review.md), [ревью кода](review.md), [план проверок](test-research.md).

LOG170 закрывает транзакционный аудит полного жизненного цикла (`create`, `update`, `delete`) и каскадных удалений пунктов навигационного меню (`core."navigationMenuItem"`). Подключены `NavigationMenuItemService` (`create`, `createMany`, `update`, `updateMany`, `delete`, `deleteMany`), `NavigationMenuItemResolver`, AI-инструменты (`CreateNavigationMenuItemTool`, `UpdateNavigationMenuItemTool`, `DeleteNavigationMenuItemTool`), фоновая очистка (`NavigationMenuItemDeletionService.deleteNavigationMenuItemsForDeletedRecords`), создание и удаление объектов (`ObjectMetadataService.createOneObject`, `deleteOneObject`, `deleteManyObjectMetadatas`, резолвер, контроллер, AI-инструменты), деактивация и удаление полей (`FieldMetadataService.updateOneField`, `deleteOneField`, резолвер, контроллер, AI-инструменты), физическое удаление представлений (`ViewService.deleteOne` / `destroyOne`), макетов страниц (`PageLayoutService.destroy` / `destroyMany`), каналов чата агентов (`AgentChatChannelMetadataService.deleteChannel`), dev-seeder (`seedPageLayouts`), миграции манифеста и удаление приложений (`runAuditedApplicationMetadataMigration`, `reconcileApplicationRoleAndPermissionOperations`, `assertNoRemainingApplicationRoleOrPermissionMetadata`) и `WorkspaceMigrationRunnerService.executeRun`.

В `crm-audit-transaction-context.ts` список `ADMINISTRATIVE_ACTIONS.navigationMenuItem` расширен до `['create', 'update', 'delete']` с редактированием отображаемых полей `['name', 'link', 'icon', 'color', 'position']` и сохранением идентификаторов связей (`['userWorkspaceId', 'folderId', 'type', 'viewId', 'targetObjectMetadataId', 'targetRecordId', 'pageLayoutId', 'agentChatChannelId']`). Создан модуль `navigation-menu-item-audit.ts` (`captureNavigationMenuItemAudit`, `withNavigationMenuItemAudit`, `runAuditedNavigationMenuItemMigration`, `computeCascadeDeletedNavigationMenuItemIds`, регистрация в `registerMetadataAuditScopeCheck`), который захватывает идентичность синхронно до первого `await`, связывает субъекта с `core."userWorkspace"`, удерживает блокировки `core.workspace` / `core."userWorkspace"` (`FOR NO KEY UPDATE`) и `core."navigationMenuItem"` / `core.view` / `core."pageLayout"` (`ORDER BY id FOR UPDATE`), вычисляет транзитивное замыкание вложенных папок и каскадных удалений родительских сущностей (`objectMetadata`, `fieldMetadata -> view`, `view`, `pageLayout`, `agentChatChannel`), сверяет сохранённые строки с планом миграции и повторно проверяет снимок после `audit.flush()`.
