# LOG136 — подключение аудируемой очистки переписки

Адресная очистка подключена к четырём реальным путям: удаление при синхронизации,
исключение групповых писем, очистка папки и удаление отправленного черновика.
Каждый закрытый owner перепроверяет собственное основание операции внутри
strict/exclusive workspace transaction и завершает общий аудит после всех изменений.

Синхронизация проверяет текущий run; групповые письма классифицируются по
заблокированным актуальным FROM participants. Папка обрабатывается страницами
по 200 строк с проверкой mapping/action и исходного диапазона до первого удаления.
Черновик привязан к конкретной association, переданной провайдеру, действующему
пользователю, membership и доступному account. Ошибка последующей очистки не
превращает подтверждённую отправку в ошибку, предлагающую повторить send.
