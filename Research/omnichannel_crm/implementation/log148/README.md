# LOG148 — аудит повторного сопоставления участников

Проверки доработки завершены. ROB765 остаётся In Progress.
[Дизайн](design.md), [ревью решения](design-review.md), [ревью кода](review.md).

LOG148 переводит повторное сопоставление участников переписки с контактами и сотрудниками на закрытые страницы с аудитом. Исправлена очистка устаревшей связи с сотрудником. Проверяются актуальные исходные связи, побочные изменения и фактический результат записи.

Существующий MessageParticipantMatchParticipantJob сохраняет порядок обработки
контактов и сотрудников. Оба массива проверяются и копируются до первой страницы.
Страницы по 200 кандидатов имеют отдельные операции аудита и общую correlation.

Person mode сохраняет первенство primary email, прежние правила additional email,
выбор удалённых контактов и исключение APP. Member mode сохраняет точный регистр
email, противоположную связь personId и цели диалога. Кандидаты берутся из текущих
заблокированных строк. Источники и APP policy защищены блокировками и повторными
проверками. Участник и автоматические цели записываются с аудитом одной транзакции.

Побочные изменения источников и целей проверяются до расчёта новых целей.
Фактический RETURNING, generated columns, incoming FK, пропущенные updates,
поздние триггеры и потеря COMMIT ACK проверены на PostgreSQL. Ранние успешные
страницы сохраняются при сбое последующей страницы.
