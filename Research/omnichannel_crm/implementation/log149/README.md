# LOG149 - аудит сопоставления участников после импорта сообщений

Проверки доработки завершены. ROB765 остаётся In Progress.
[Дизайн](design.md), [ревью решения](design-review.md), [ревью кода](review.md), [адаптеры источников](callers-review.md).

LOG149 переводит сопоставление участников и обновление целей диалога после сохранения сообщений на закрытые страницы с аудитом. Атрибуция и актуальные полномочия захватываются для входов provider, inbound, sent, sent-tool и application.

Обычный агрегат сохранения фиксирует неизменяемый манифест реально вставленных и изменённых участников, а также пар Message/Thread до постановки задания создания контактов. В режиме both обновляются только затронутые участники, а исторические ручные связи неизменённых участников сохраняются. Сохранённые сообщения без изменённых участников и источник APP в режиме targetsOnly обновляют цели диалога без перезаписи связей участников.

Каждая страница до 200 записей выполняется в собственной strict/exclusive транзакции с общим correlationId. Проверяются актуальный ожидаемый запуск провайдера, получатель EMAIL_GROUP, доступность и отсутствие архивации аккаунта отправки, принадлежность приложения и агента, неизменность типа канала, исходные связи, фактический RETURNING, вычисляемые поля, внешние ключи и побочные триггеры до расчёта целей и после deferred drain. Успешная внешняя отправка сохраняет свой результат при последующем сбое записи или логирования.
