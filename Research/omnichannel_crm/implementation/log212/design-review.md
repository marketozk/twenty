# LOG-212: Independent Design Review

## Verdict
`pass` (all 2 blockers, 4 majors, and 3 minors resolved in revised `design.md` and `test-research.md`)

## Findings and resolutions

| # | Severity | Finding | Resolution in revised design |
|---|---|---|---|
| B1 | blocker | Creating a new resolver importing `AdminPanelGuard`/`AuthPrincipalGuard`/`ResolverValidationPipe` and a service importing `TwentyConfigService`/`SecureHttpClientService` introduces new `runtime_enterprise_reachable` files and `enterprise_edges`, failing `check_enterprise_dependencies.py --verify-baseline` | Added `crmAuditHealth` query directly onto existing `AdminPanelResolver` (which already owns those baseline edges); kept `crm-audit-health.dto.ts` importing only `@nestjs/graphql` + `class-validator`; built `CrmAuditAlertSinkService` and `CrmAuditHealthModule` exclusively from non-enterprise-reachable modules (`@nestjs/config` `ConfigService`, `ExceptionHandlerService`, `createSsrfSafeAgent`, `normalizeAllowedInternalHost`, `axios`). |
| B2 | blocker | `@IsOptional()` + `@IsUrl()` on `CRM_AUDIT_ALERT_WEBHOOK_URL` crashes boot on `""` and contradicts graceful invalid-URL degradation; empty numeric env vars coerce to `0` in `CastToPositiveNumber` | Used `@IsOptionalOrEmptyString()` + `@IsString()` without `@IsUrl()` on `ConfigVariables`; performed strict `http:`/`https:` URL validation and numeric default/clamping inside `CrmAuditAlertSinkService`. |
| M3 | major | Splitting `checkHealth()` and `getSnapshot()` allows torn health responses; `bypassCache: true` skipped `inFlightProbes` allowing concurrent DB probe DoS | Populated `recentWindowMs`, `countsByCode`, and `recentFailures` directly on `CrmAuditDatabaseHealthStatus` from the single post-probe snapshot, and added `inFlightBypassProbes` single-flight coalescing. |
| M4 | major | `AdminPanelGuard` threw `TypeError` on missing `request.user`; `AuthPrincipalGuard` allowed `impersonated: true` | Hardened `AdminPanelGuard` with `Boolean(request?.user)` check; set `impersonated: false, playground: false` on method-level `AuthPrincipalGuard` matching `getServerAdmins`. |
| M5 | major | `maxRedirects: 5` could leak `X-Twenty-Audit-Alert-Signature` or turn POST into GET; Axios errors/logging could leak URL/IP; `isSensitive: true` alone exposes last 4 chars in Admin Panel config UI | Set `maxRedirects: 0`; never log `error.message`/`error.config`/`error.response?.data` (safe code only); added `isHiddenInAdminPanel: true` alongside `isSensitive: true` on webhook URL and secret. |
| M6 | major | Concurrency drop or delivery failure could erase `suppressedCount`/poison cooldown; shared Sentry/Webhook throttle coupled channels; double `onModuleInit` could double-register; `onModuleDestroy` did not abort in-flight webhooks | Checked concurrency limit before mutating throttle state; restored unsent `suppressedCount` on delivery failure; separated `sentryThrottleByCode` and `webhookThrottleByCode`; made `onModuleInit` idempotent; tracked `AbortController`s and destroyed HTTP agents in `onModuleDestroy`. |
| m7 | minor | `ResolverValidationPipe` returns raw input without class defaults; GraphQL explicit `null` bypasses `defaultValue` | Marked `CrmAuditHealthInput` fields nullable + `@IsOptional()` + `Int` and applied defaults in the resolver; registered `CrmAuditHealthStatus` via `registerEnumType`. |
| m8 | minor | Plain `Error` with per-event `operationId` in `message` explodes Sentry issue grouping | Set `CrmAuditUnavailableError.name = 'CrmAuditUnavailableError'` and `message = record.code` only (no per-event IDs in `message`). |
| m9 | minor | Axios 1.x default `transformRequest` can double-encode string `rawBody` and break HMAC-SHA256 verification | Passed `transformRequest: [(data) => data]` so wire bytes match HMAC input byte-for-byte. |
