# LOG143 — сохранение событий календаря с аудитом

CalendarSaveEventsService сохраняет Event, Association и Participant через
существующие репозитории в одной strict/exclusive транзакции с общим аудитом.
Планировщики sharing и участников сохранены. Обе точки входа передают захваченного
автора: фоновый import — именованный system, ручное создание — request/tool identity
до внешнего вызова. Имитации sync run для ручного создания нет.

Проверяются актуальные источники, пять таблиц графа, фактический RETURNING,
вычисляемые PostgreSQL поля, входящие FK effects и поздние изменения после
audit flush и deferred constraints. Незаписанный Event не оставляет зависимые
записи; повтор нового ключа участника отклоняется до первой записи.

Сопоставление контактов выполняется после подтверждённого сохранения. Его ошибка
классифицируется как postcommit; ручное создание сохраняет успешный результат
провайдера даже при сбое локальной записи или логирования.
