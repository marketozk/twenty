## Ограничения и исправления процесса

- В CLI review slash skills отключались. Проверку проводил Claude Code по переданному контракту; фактически сообщённая модель claude-opus-5-5. Это не «все скиллы запущены внутри Claude».
- В R5/R6 prompt запрещал MCP, но реальный журнал показал служебные task-card updates. В R7 запретили обнаруженный tool явно, его вызовов нет. [Точный audit](plan/cross-review/cli-tool-audit.json). Следовательно, прежнюю фразу «MCP не использовался» нельзя распространять на R5/R6.
- Предыдущая работа исправляла основной план (diff и §15 подтверждают), но наращивание добавочных секций сохранило противоречия. После R7 последние четыре исправления оставались proposal. В текущем шаге они внесены в основной spec и связанные документы; состояния — addressed_pending_review, не pass.
- При отсутствии сходимости нужно менять структуру контракта, а не просить разрешение на каждую очевидную документальную правку. Повторение того же review-цикла не проводится. Следующая независимая проверка относится к новой согласованной редакции.
- Использовать весь каталог скиллов подряд не требуется. Нужен проверяемый результат подходящих процедур; новые runtime проверки остаются частью реализации.
